# Results

Nothing in this directory is a benchmark claim.

`run_eval.py` writes JSON and Markdown here when you point it at a query file and a live index. Those files describe that run only. The README table is the 10 Nov 2026 cloud measurement (3 clips, 21 scored test queries). A new run does not replace that table until you decide it should.

Do not copy a smoke-test number into the README or a CV bullet.
